# Claude Code Project Guide

Read `AGENTS.md` first. It is the canonical project operating guide.

This repo also keeps portable skills in `.agents/skills/`. When a task matches
one of those skills, use the skill workflow even if Claude Code does not expose
it as a slash command in the current session.

Useful skill names:

- `codebase-research`
- `architecture-plan`
- `fullstack-architect`
- `implementation-agent`
- `systematic-debugging`
- `test-driven-development`
- `test-and-verify`
- `code-review`
- `security-review`
- `docs-sync`
- `unity-ml-agents`

Before finishing, report files changed, verification run, and remaining risks.
